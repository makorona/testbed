# PULSE — Session Hijacking Testbed

Учебная социальная сеть для демонстрации атак на сессионные токены
и работы детектора аномалий. Дипломный проект по информационной безопасности.

## Запуск локально
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## Деплой на Render
Подключить репозиторий — Render использует render.yaml автоматически.

## Карта страниц
- `/`           — лендинг PULSE
- `/register`   — регистрация (имя, email, телефон, пароль)
- `/login`      — вход
- `/feed`       — лента (профиль, посты, индикатор сессии)
- `/messages`   — личные сообщения (приватные данные)
- `/settings`   — настройки аккаунта (email, телефон, пароль)
- `/stealer`    — страница-приманка (фейковый PULSE Premium) — крадёт demo_token
- `/attacker`   — панель атакующего (C2) с кнопками действий
- `/logs`       — журнал детектора аномалий

## Сценарий демонстрации
1. Зарегистрироваться и войти (жертва)
2. Открыть /stealer и нажать "Активировать" — токен украден
3. Открыть /attacker — увидеть токен и метаданные жертвы
4. Кнопки: читать сообщения, сменить email (захват), сменить пароль (блокировка), спам
5. Включить тумблер "Детектор аномалий" — те же действия блокируются
6. /logs — вся история сессий и событий

## Детектор
Признаки: смена IP (+40), смена User-Agent (+30).
Пороги: OK (0) / ALERT (>=30) / BLOCK (>=60).
При включённой защите любое аномальное действие (ALERT/BLOCK) блокируется.
